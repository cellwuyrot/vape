# Чек-лист по персональным данным (152-ФЗ) перед запуском CRM

Актуально с учётом редакции ч. 5 ст. 18 152-ФЗ, действующей с 01.07.2025.

## 1. Локализация данных
- [ ] Файл базы (DATA_DIR, node:sqlite) и постоянный диск размещены в дата-центре на территории РФ.
- [ ] Резервные копии и файловое хранилище — также в РФ.
- [ ] В договоре с хостингом или облаком явно указана юрисдикция серверов (РФ).
      Подходят: Яндекс Облако, VK Cloud, Selectel, Timeweb, REG.RU, собственный ЦОД.
- [ ] Письмо или сертификат провайдера о местонахождении серверов хранится в пакете документов оператора.
- [ ] CDN и WAF — российские, либо через них не проходят формы с ПДн.

Штрафы за нарушение локализации (ч. 8–9 ст. 13.11 КоАП): 1–6 млн ₽,
повторно — 6–18 млн ₽. Практика 2025 года: 1,5–4 млн ₽ за CRM на зарубежных серверах.

## 2. Основания обработки
- [ ] Согласие на обработку ПДн фиксируется при регистрации сотрудника
      (поле `users.pd_consent_at`) и в карточке клиента (`contacts.pd_consent_at`).
- [ ] Текст согласия и политика обработки ПДн опубликованы и доступны без ограничений.
- [ ] Заданы сроки хранения (`contacts.pd_retention_until`) и настроено регулярное
      удаление устаревших данных.

## 3. Обработчики и договоры поручения
Договор поручения обработки ПДн нужен с каждым сервисом, через который проходят данные:
- [ ] Оператор телефонии;
- [ ] Wazzup24 или иной агрегатор мессенджеров;
- [ ] SMS-шлюз (SMS.RU, SMSC.RU);
- [ ] Сервис e-mail-рассылок (Unisender, Sendsay, DashaMail);
- [ ] Хостинг-провайдер или облако;
- [ ] Подрядчик по поддержке CRM, если у него есть доступ к базе.

Зарубежные Mailchimp, SendGrid, Zapier, Make для данных граждан РФ использовать нельзя.

## 4. Уведомления Роскомнадзора
- [ ] Подано уведомление о начале обработки ПДн (штраф за отсутствие — 100–300 тыс ₽).
- [ ] При любой трансграничной передаче — отдельное уведомление до её начала
      через pd.rkn.gov.ru и получение разрешения.

## 5. Технические меры (реализовано в коде)
- [x] Пароли хранятся в виде scrypt-хеша, коды подтверждения — в виде HMAC-SHA-256-хеша.
- [x] Разграничение прав: роли admin / manager / agent / viewer.
- [x] Журнал действий с ПДн: чтение, изменение, удаление, поиск, экспорт (`audit_log`).
- [x] Вебхуки защищены секретом в URL.
- [ ] HTTPS с российским или доверенным сертификатом.
- [x] Ограничитель частоты запросов на регистрацию, вход, подтверждение и вебхуки.
- [x] Веб-шрифты хранятся локально: страница не обращается к внешним доменам.
- [ ] Ограничение на массовый экспорт базы и алерт на аномальную активность.
- [ ] Регулярный пересмотр списка сотрудников с доступом (увольнения, смена ролей).

## 6. Организационные меры
- [ ] Назначен ответственный за организацию обработки ПДн.
- [ ] Утверждены политика обработки, перечень ПДн, модель угроз.
- [ ] Ведётся реестр систем, где хранятся ПДн: CRM, 1С, почта, телефония, бэкапы.
- [ ] Проводится ежеквартальный аудит по пунктам этого чек-листа.

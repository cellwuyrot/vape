# Каталог VAPELAB — покрытие демонстрационной сборки

## Состав

- 18 основных категорий каталога.
- 5 вложенных категорий/коллекций.
- 77 товарных записей в исходной демонстрационной базе этой сборки.
- Вложенные варианты теперь поддерживаются отдельной таблицей и XLSX-импортом; число вариантов зависит от добавленных менеджером строк.
- Исходные фотографии товаров не входят в демонстрационную выгрузку. Фирменный логотип предоставлен владельцем и установлен.

## Ограничение по количеству

Требование «2–6 примеров в каждой категории» нельзя полностью выполнить без выдумывания ассортимента. В исходном публичном каталоге несколько разделов показывают только одну карточку. Поэтому они оставлены с фактическим количеством вместо синтетических товаров:

- POD-системы на заправляемых картриджах — одна публично найденная позиция: [категория](https://vapelab.tech/collection/pod-sistemy-na-zapravlyaemyh-kartridzhah).
- Сигареты — одна публично найденная позиция: [категория](https://vapelab.tech/collection/sigarety).
- Топливо для зажигалок — одна публично найденная позиция: [категория](https://vapelab.tech/collection/toplivo-dlya-zazhigalok).
- Энергетические паучи — одна публично найденная позиция: [категория](https://vapelab.tech/collection/energeticheskie-pauchi).

Вложенная коллекция «Армянские сигареты» связана с найденной карточкой Cigaronne в миграции `008_vapelab_taxonomy_fix.sql`: [исходная коллекция](https://vapelab.tech/collection/armenianskie-sigarety).

Остальные записи в каталоге сохраняются как демонстрационное наполнение текущей базы. Их наименования, характеристики, цена, наличие, фотографии и право использования изображений должны быть сверены с полным экспортом владельца перед публикацией в рабочем магазине.

## Следующий источник для точного переноса

Нужен экспорт из админки текущего сайта в XLSX/CSV с полями SKU, категории, вариантов, исходной строки цены, наличия, описания, фото URL и адреса исходной карточки. Дальше этот экспорт можно прогнать через предварительный просмотр CRM и сопоставить без автоматического объединения разных SKU.

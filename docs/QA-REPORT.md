## Непройденные/внешние проверки

- Playwright Chromium не смог открыть `http://127.0.0.1:3117/`: браузер вернул `ERR_BLOCKED_BY_ADMINISTRATOR`. Поэтому реальный pixel/visual browser QA на desktop/mobile в этой среде не выполнен; внешний вид требует проверки в браузере пользователя.
- Доступность React ESM runtime с `esm.sh` из браузера пользователя не подтверждена. При недоступности CDN React Bits SpotlightCard оставляет обычные серверные карточки активными, но без spotlight.
- Точная интеграция OriginKit Hero 58 не выполнена: реализована оригинальная canvas-анимация в том же визуальном направлении, не скачанный компонент.
- Chroma Grid не подключён до появления проверенных оригинальных фото товаров.
- Публикация, production SMTP, production package build, реальный внешний image search и производственная база не затрагивались.

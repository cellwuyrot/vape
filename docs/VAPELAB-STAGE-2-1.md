# VAPELAB — промежуточный этап 2.1

Это рабочая промежуточная сборка витрины поверх RuCRM. Она предназначена для локального просмотра и дальнейших итераций, а не для публикации.

## Изменения этапа

- Переработана главная страница: шапка, блок о компании, два направления, каталог, новости и контакты.
- Каталог выводит корневые категории, вложенные коллекции и товарные карточки по разделам.
- Карточки получили редакционные графические обложки на CSS. Это не фотографии товаров и не изображения производителя.
- В публичной новостной ленте доступны шесть публикаций, найденных в исходном блоге; историческая акция Halloween явно помечена как завершившаяся 01.11.2026.
- Визуальные настройки CRM предусматривают прямые URL логотипа и favicon. Логотип должен быть SVG/PNG/WebP; область логотипа круглая, фон белый.
- Добавлена нейтральная адаптация интерфейса с Unbounded для заголовков и Inter для текста.

## Состав демонстрационного каталога

- 18 основных категорий.
- 5 вложенных категорий.
- 76 опубликованных примеров товаров.
- В четырёх корневых разделах пока только по одной подтверждённой позиции. Это отражает объём найденных карточек, а не подтверждает полноту исходного каталога.
- Для ряда карточек подробное описание, точный SKU, отдельная страница товара или отдельная фотография не найдены. Эти данные не выдумываются.

## Ограничения

- В исходной выборке нет загруженных фотографий товаров: используются типографические CSS-обложки с названием товара.
- Пользовательский логотип по ссылке `https://ibb.co/Pshj908H` не удалось получить как файл. В шапке пока используется нейтральный знак `V`. Для установки фирменного логотипа нужен сам файл или прямой URL изображения.
- Публичная хронология основания/развития бренда не подтверждена источниками; текст раздела о компании ограничен сведениями публичного сайта.
- Юридические страницы оставлены для отдельного согласования с владельцем и юристом.
- Каталог остаётся информационной витриной: в этой итерации нет корзины, оформления покупки и платёжных действий.

## Проверки

- `npm run lint` — пройдено.
- `npm test` — 115 тестов пройдены.
- Тестовая БД применяет миграции до версии 6.
- Проверка локального API: 23 категории (18 корневых + 5 вложенных), 76 товаров, 6 публикаций.

## Запуск

```bash
npm start
```

Затем открыть `http://localhost:3000/`. Панель CRM: `http://localhost:3000/crm`.

Перед обновлением существующей рабочей копии сохранить `.env` и `data/` — там хранится локальная БД и файлы CRM. Предпочтительно сначала распаковать этап в отдельную папку и сравнить изменения.

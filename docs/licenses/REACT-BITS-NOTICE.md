# Third-party notice: React Bits SpotlightCard

## Статус текущего ZIP

Upstream-исходник React Bits SpotlightCard **не включён** в текущий распространяемый архив VAPELAB. В проекте подготовлены официальный registry configuration, PowerShell-установщик и адаптер, который сможет обнаружить установленный компонент в `storefront-react/src/components/visuals/`. До установки работает независимо написанный fallback `VapelabGlowCard`.

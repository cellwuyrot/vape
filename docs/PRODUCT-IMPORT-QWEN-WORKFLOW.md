# Импорт каталога VAPELAB: XLSX/CSV, изображения и Qwen Code

## 1. Как сейчас устроен импорт товаров

Мастер CRM принимает `.xlsx` и `.csv`. `.xls` не поддерживается: старую книгу нужно пересохранить в `.xlsx` или `.csv`. Для XLSX читается первый лист. Первая строка трактуется как заголовки, следующие строки — записи товаров.

Путь: **CRM → Импорт → Товары витрины VAPELAB**.

После загрузки файла CRM показывает предпросмотр и для каждой исходной колонки отдельный список целевых полей. Пользователь может:

- принять предложенное автоматическое сопоставление;
- вручную назначить другое поле;
- выбрать «не импортировать»;
- отключить автоматическое сопоставление и собрать схему вручную;
- выполнить пробный импорт и увидеть строки с ошибками до записи в базу.

Одинаковое целевое поле нельзя назначить двум исходным колонкам: сервер отклоняет такую схему вместо молчаливой перезаписи значения. Обязательное поле товара — название.

## 2. Поля карточки товара, доступные в CRM

| CRM-поле | Назначение |
|---|---|
| `name` | Название товара (обязательное) |
| `sku` | Артикул / SKU |
| `brand` | Бренд / производитель |
| `category_name` | Основная категория |
| `subcategory_name` | Подкатегория |
| `product_type` | Тип товара |
| `format` | Формат / модификация |
| `description` | Описание |
| `price_raw`, `old_price_raw`, `currency` | Цена как в источнике, старая цена и валюта |
| `availability_label_raw` | Исходная подпись наличия |
| `source_url` | Страница, откуда взяты факты |
| `status` | `draft`, `pending_review`, `published`, `archived` |
| `seo_h1`, `seo_title`, `seo_description`, `seo_keywords` | Заголовок, title, description и ключевые фразы |
| `canonical_url`, `robots_index` | Canonical и разрешение индексации (1/0) |
| `search_volume`, `frequency_class`, `search_engine`, `search_region`, `search_intent`, `search_source`, `search_checked_at` | Данные исследования поискового спроса и их источник |
| `image_url`, `image_alt`, `image_source_url`, `image_search_query` | Изображение и его происхождение |
| `variant_name`, `variant_sku`, `variant_price_raw`, `variant_old_price_raw`, `variant_availability_label_raw` | Данные варианта товара |
| `taste`, `volume`, `strength`, `color`, `package`, `compatibility`, `variant_attributes_json` | Вкус, объём, крепость, цвет, комплект, совместимость и дополнительные атрибуты |
| `is_18_plus` | Требуется проверка возрастного ограничения (1/0) |
| `is_reservable` | Разрешено ли бронирование (1/0) |

В шаблоне `templates/VAPELAB-products-template.xlsx` есть 45 колонок, совпадающих с экспортом скрипта. Все 45 заголовков проверены автоматическим тестом на сопоставление с полями CRM.

## 3. Python-парсер

Файлы:

- `tools/vapelab_catalog_parser.py` — сбор открытых фактов и упаковка результата.
- `tools/requirements-vapelab-parser.txt` — Python-зависимости.
- `tools/test_vapelab_catalog_parser.py` — офлайн-тесты извлечения и формирования импорта.

Установка зависимостей Windows CMD из корня проекта:

```cmd
py -m pip install -r tools\requirements-vapelab-parser.txt
```

Сначала рекомендуется небольшой тестовый запуск — пять коллекций и до пятнадцати карточек:

```cmd
py tools\vapelab_catalog_parser.py crawl --output .\qwen-workspace --max-collections 5 --max-products 15
```

Если владелец сайта подтвердил право на аудит, но `robots.txt` источника недоступен, можно явно добавить `--owner-confirmed`. Этот флаг не обходит CAPTCHA/авторизацию/антибот и не отменяет запреты, которые удалось прочитать из robots.txt.

Если есть право скачивать и повторно использовать изображения, включите:

```cmd
py tools\vapelab_catalog_parser.py crawl --output .\qwen-workspace --max-collections 5 --max-products 15 --download-images
```

После проверки небольшой выборки можно увеличить лимиты. По умолчанию парсер сам ограничен 400 коллекциями и 10 000 уникальных карточек; задержка между запросами — 1,5 секунды. При необходимости задавайте `--delay` больше.

## 4. Структура папок и manifest

```text
qwen-workspace/
  QWEN.md
  manifest.json
  collections.json
  products-raw.csv
  products-import.csv            # создаётся после Qwen package
  .qwen/
    commands/
      enrich-catalog.md
  products/
    <product-slug>/
      source.json                # исходные факты, URL, наблюдения цены/наличия
      enriched.json              # только результат Qwen
  images/
    <product-slug>/
      01-image.webp
      02-image.jpg
```

Папки изображений именуются по slug товара. Поэтому фотографию можно сопоставить с уже импортированной карточкой при загрузке папки фотографий через CRM. CSV и папка фотографий загружаются двумя действиями: сначала товары, затем папка изображений.

`manifest.json` — **прикладной manifest этого парсера**, а не специальный встроенный формат Qwen Code. Один объект `items[]` описывает одну карточку: её ID/slug, исходный файл, папку фотографий, выходной `enriched.json`, статус обработки и поля, требующие проверки.

## 5. Как работать с Qwen Code локально

Запустите Qwen Code из папки `qwen-workspace`. В ней уже будут:

- корневой `QWEN.md` с краткими постоянными правилами;
- проектная slash-команда `.qwen/commands/enrich-catalog.md`;
- `manifest.json`, который ограничивает задание конкретными ID/slug и путями файлов.

Команды:

- `/enrich-catalog 5` — подготовить не более пяти первых записей со статусом `pending`;
- `/enrich-catalog glo-air-belyy` — обработать только одну карточку по её slug;
- `/enrich-catalog` — то же безопасное пакетное поведение по умолчанию (до пяти записей).

Qwen должен читать `source.json` выбранного товара и записывать только `enriched.json`. Он может подготовить нейтральное описание, тип, формат, H1, SEO title, SEO description и ключевые фразы на основе source facts. Он не должен менять цену, SKU, наличие, бренд, возрастное решение, бронирование, публикацию или индексацию.

## 6. Сборка CSV и импорт в CRM

После Qwen обогащения вернитесь в корень проекта VAPELAB и выполните:

```cmd
py tools\vapelab_catalog_parser.py package --workspace .\qwen-workspace
```

Если остаются позиции без `enriched.json`, экспорт по умолчанию остановится и покажет количество необработанных товаров. Это предотвращает незаметный пропуск части каталога. Для осознанного экспорта одних исходных данных существует `--include-unenriched`, но перед импортом такие позиции следует просмотреть вручную.

Полученный `products-import.csv` загрузите в **CRM → Импорт → Товары витрины VAPELAB**. На шаге сопоставления:

1. Проверьте все 45 предложенных назначений.
2. Столбцы, которых нет в исходнике, оставьте как «не импортировать».
3. Убедитесь, что `SEO Description` назначено в SEO Description, а не в обычное описание.
4. Убедитесь, что `Название варианта` назначено в `variant_name`.
5. Проведите пробный импорт.
6. Проверьте категории, варианты, цену и журнал ошибок.
7. Выполните реальный импорт только после успешного пробного.
8. При наличии скачанных фотографий загрузите папку `images` через действие загрузки папки фотографий в разделе товаров.

## 7. Защитные значения по умолчанию

Экспортёр принудительно задаёт:

- `status=draft`;
- `robots_index=0`;
- `is_reservable=0`;
- `is_18_plus=1` для категорий, требующих возрастной проверки, иначе поле остаётся пустым для ручной проверки.

Qwen не может переопределить эти значения: `enriched.json` валидируется, а любые незапрошенные поля (например `price_raw`, `sku`, `status`, `is_reservable`) отклоняются. Парсер сохраняет цену/SKU только из наблюдений исходного сайта и не угадывает отсутствующие значения.

Перед публикацией нужно проверить право на повторное использование изображений/текстов, цены и статусы, возрастную классификацию, юридические тексты и разрешённость публичной индексации.

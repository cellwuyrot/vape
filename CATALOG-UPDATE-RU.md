# Обновление каталога и поиска VAPELAB

Это архив-патч, а не полный проект. Он подготовлен относительно ветки main, коммита be856d8. Распаковывать в корень чистой локальной копии репозитория после проверки её версии. На работающий сервер его автоматически не устанавливали.

## Что изменено

- Отдельная страница /catalog/categories: разделы, поиск категорий и фильтр по первой букве, адаптация для телефона. Прямая ссылка на подраздел, адреса старых категорий сохраняются.
- Главная страница больше не раскрывает длинные списки: ссылка на каталог и основные направления. Навигация загружает облегчённый набор данных.
- Общий поиск показывает категории и опубликованные товары, учитывает название, бренд, артикул, варианты, транслитерацию и некоторые опечатки. Все слова запроса должны совпасть. Поиск на отдельной странице можно ограничить категорией, включая вложенные.
- Собранные файлы React уже включены. Миграций и изменений зависимостей нет.

## Проверки

- Сборка витрины и проверка синтаксиса прошли. Целевые тесты: 38 из 38.
- В локальном браузере проверены мобильная и настольная версии, 68 категорий, фильтры и работа каталога без JavaScript.
- Полный npm run check: 214 из 226 тестов прошли. 12 ошибок воспроизводятся и в исходной версии: старые ожидания админки/данных SEO, состав почтового сервера и email webhook. Полный набор не является зелёным; результаты нужно отдельно разобрать перед промышленной эксплуатацией.
- На локальном синтетическом наборе из 10 020 товаров поиск занимал примерно 0,4–0,6 с на запрос. Это не испытание производственной нагрузки; поиск пока перебирает записи, для большого каталога стоит проверить нагрузку и при необходимости добавить индексирование.
- С боевой базой и PostgreSQL проверки не проводились.

## Публикация в Git

1. Сделайте копию локального репозитория и убедитесь, что изменения не перезапишут вашу работу. Проверьте актуальность main относительно be856d8: если файлы после этого коммита изменялись, сначала разберите конфликт вручную.
2. Распакуйте архив в корень репозитория. Проверьте git diff и git status, запустите npm run check (известные ошибки указаны выше). Затем создайте ветку и зафиксируйте только файлы этого обновления:

```sh
git switch -c feature/catalog-navigation
git add -- CATALOG-UPDATE-RU.md public/catalog-browser.js public/customer-tools.css public/customer-tools.js public/react-app/assets/vapelab-storefront.css public/react-app/assets/vapelab-storefront.js public/react-app/assets/vapelab-storefront.js.map public/seo-pages.css server/catalog-search.js server/public-pages.js server/routes/store.js storefront-react/src/main.js storefront-react/src/styles.css test/catalog-directory.test.js test/react-storefront.test.js
git diff --cached --stat
git commit -m "Improve catalog navigation and search"
git push -u origin feature/catalog-navigation
```

Затем создайте и проверьте pull request и объедините его с main. Если ветка уже существует, выберите другое имя. Не включайте в Git .env, базу, загрузки и резервные копии.

## Важно для действующего сервера

/var/www/vapelab/app ранее не был Git-репозиторием: команда git pull там не заработает, пока устройство развёртывания не будет отдельно изменено. Не инициализируйте Git поверх работающего приложения без сверки файлов.

На сервере уже применены старые миграции 004, 005, 006 и 008, которые отличаются от публичного репозитория. **Не заменяйте их версиями из Git и не публикуйте серверные миграции с приватными данными.** Не перезаписывайте .env, data, файлы пользователей, логи, mail-server, локальную конфигурацию PM2 и прочие серверные настройки. Патч эти файлы не содержит.

Перед обновлением нужно сравнить нужные файлы с текущей версией сервера, подготовить свежую проверенную резервную копию базы, загруженных файлов и кода, проверить обновление на копии и лишь затем переносить выбранные файлы, сохраняя серверные миграции. Node.js 22, рабочий каталог /var/www/vapelab/app, процесс PM2 vapelab. Новая миграция для данного патча не требуется. Не выполняйте npm ci и npm run migrate автоматически, если у вас нет отдельной причины; собранная витрина включена.

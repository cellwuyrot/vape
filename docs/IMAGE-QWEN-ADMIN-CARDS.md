# Подбор изображений и карточки категорий VAPELAB

## Поиск и добавление фотографии

В CRM откройте `Витрина → Товары → Фото`.

1. Кнопка «Скопировать задание для Qwen» формирует запрос с названием, брендом, SKU, вариантом и slug товара.
2. В Qwen Code выполните `/tools`. Встроенный `web_search` доступен только для поддерживаемых провайдеров/режимов, а `web_fetch` извлекает страницы и может сохранять бинарные файлы. Если инструменты не отображаются, Qwen не должен имитировать поиск.
3. Ищите официальный сайт производителя и медиатеку. Картинки скачивайте в `qwen-workspace/images/<slug>/` только при подтверждённых правах на коммерческое использование. Для сомнительного источника оставляйте URL и `needs_review` в `image-sources.json`, но не скачивайте.
4. Вернитесь в окно Фото и загрузите выбранные файлы с компьютера. Файлы привязываются непосредственно к открытой карточке товара.

Yandex Search API теперь необязателен. Если ключи Yandex не заданы, сервер возвращает инструкцию по локальному процессу Qwen, а не ошибку 503. Существующий URL-поиск Yandex продолжает работать при наличии ключей.

## Поля и тексты

Qwen может создавать самостоятельное нейтральное описание, тип/формат, SEO H1, Title, Description и релевантные Keywords по подтверждённым фактам. Нельзя придумывать цену, SKU, наличие, характеристики, возрастную классификацию, статус публикации и возможность бронирования. Нельзя копировать описание конкурента дословно.

## Товар-представитель категории

В CRM откройте `Витрина → Категории → Изменить` и выберите «Товар-представитель категории». В списке только опубликованные товары, уже привязанные к данной категории. На публичных карточках категорий фото и название этого товара проявляются при наведении; увеличение намеренно небольшое. При reduced-motion анимации отключаются.

## Что проверить после установки

- Фото открывает диалог, полностью помещающийся в окне.
- Можно скопировать Qwen-задание, выбрать несколько локальных файлов и добавить проверенный HTTPS URL.
- Поиск по каталогу сохраняет фокус и курсор после серверного обновления.
- Товар-представитель выбранной категории виден посетителю на главной и в раскрытом списке категорий.

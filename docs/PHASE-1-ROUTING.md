# VAPELAB — этап 1: маршрутизация и серверная основа

## Изменения

- `/` обслуживает только публичную витрину.
- `/crm` обслуживает оболочку CRM и отдаёт `X-Robots-Tag: noindex, nofollow`.
- `/crm/` перенаправляется на `/crm` ответом `308`.
- Неизвестные HTML-адреса возвращают HTML-страницу `404.html` с HTTP 404 и `noindex, nofollow`.
- Неизвестные API-адреса возвращают JSON 404.
- Статические ресурсы выдаются только если файл существует внутри `public/`; произвольный HTML-файл напрямую недоступен.
- Проверяются декодирование URL, выход за корневой каталог и symlink-переходы.
- `robots.txt` запрещает индексацию API и CRM.
- `sitemap.xml` пока содержит только главную страницу: отдельные публичные маршруты категорий, товаров, новостей и страниц ещё не реализованы. Не добавлять URL в sitemap до проверки соответствующего маршрута.
- В production требуется корректный `PUBLIC_URL` с HTTPS, чтобы формировать абсолютные канонические адреса.

## Проверка

Команды:

```bash
npm run check
```

Результат в этой сборке:

- линтер: 70 файлов, замечаний нет;
- тесты: 125 пройдено, 0 провалено;
- ручной HTTP smoke-test: `/` — 200; `/crm` — 200; неизвестная страница `/tabak` — 404; `/robots.txt` — 200; `/sitemap.xml` — 200; отсутствующий asset — 404; прямой `/index.html` — 404.

## Актуализация статуса в Phase 6

Историческое описание предыдущей сборки выше не означает, что upstream-исходник React Bits включён в текущий передаваемый архив. В Phase 6 он исключён из ZIP и устанавливается владельцем из официального registry; используется независимый VAPELAB fallback до установки.

# VAPELAB Stage 4 — этап 3: короткая главная и визуальная система

Дата контрольной проверки: 2026-11-23

## Что изменено

### Главная страница
- Главная организована как короткая презентационная страница: Hero, информация о компании и направлениях, ключевые категории, новости и контакты.
- На главной не выводится весь список товарных карточек; для каталога используются отдельные страницы категорий.
- Добавлены шесть заметных переходов `/tabak`, `/stiki`, `/nagrevateli-tabaka`, `/odnorazki`, `/pod-sistemy`, `/zhidkosti`.
- Остальные разделы собраны в сворачиваемом блоке с тремя группами.
- История бренда не выдумывается: текст прямо указывает, что хронология основания не была найдена в изученных публичных материалах.
- В блоке новостей выводятся три последние публикации; на время запроса отображаются skeleton-карточки.

### Дизайн
- Восстановлена чёрно-белая основа: белая поверхность и чёрная типографика на страницах, тёмная Hero/контактная область.
- Синий `#246BDE` и голубой `#39C8EA` ограничены акцентами, интерактивными состояниями и волновой графикой.
- Используются Unbounded для заголовков и Inter для основного текста с системными fallback.
- В шапке, Hero и подвале страниц используется предоставленный знак VAPELAB на белой круглой подложке.
- Обновлён `/favicon.svg`, который теперь содержит фирменный PNG, а не прежнюю букву-заглушку.
- Серверно-рендеримые страницы категорий, товаров и новостей получили адаптивное мобильное меню; навигация закрывается по Esc, выбору ссылки и расширению окна.

### Hero 58
- Реализована canvas particle-wave композиция, адаптированная к фирменной палитре VAPELAB.
- Режим учитывает `prefers-reduced-motion`, coarse pointer, видимость секции и вкладки документа; анимация останавливается, когда секция не видна.
- Важно: это собственная визуальная адаптация по мотивам OriginKit Hero 58 / Gauze Blaze, а не скачанный исходник компонента OriginKit. Официальный CLI требует React-проекта и аутентифицированной установки; в текущей среде npm registry/CLI не были доступны для установки. Точное подключение OriginKit остаётся отдельной задачей, если будет выбран переход к полноценной React-сборке.

### React Bits
- На карточках товаров серверных страниц интегрирован React-компонент SpotlightCard, адаптированный по официальному исходнику React Bits.
- Используется `useRef` и обработчик `onMouseMove`; координаты указателя передаются через CSS custom properties `--mouse-x`, `--mouse-y`, `--spotlight-color`.
- Компонент загружается в браузере через React ESM import map с `esm.sh`; server-rendered HTML остаётся на месте, если внешний runtime не загрузился.
- При `prefers-reduced-motion: reduce` компонент не монтируется.
- Для компонента добавлено уведомление об авторстве и лицензии в `docs/licenses/REACT-BITS-NOTICE.md`.
- Это интеграция React Bits-компонента, но пока не полноценная React/Vite-сборка витрины: проект по-прежнему сохраняет текущий Node.js backend и серверную генерацию HTML.

### Карточки товаров
- Сетка увеличена: три колонки на широком экране, две на планшете, одна на узком телефоне.
- Изображения получают квадратную большую область; базовый размер карточки увеличен.
- Увеличены размеры заголовка, описания и отступы.
- Добавлены акцентная подсветка и подъём карточки при наведении.
- Оригинальные фотографии не подменяются случайными изображениями. При их отсутствии показывается нейтральный placeholder.
- Chroma Grid пока не подключён: в демонстрационной базе не хватает реальных фотографий, и без них эффект не помогает визуально проверить карточки.

## Проверка
- `npm run check`: линтер без замечаний; 132 теста пройдены, 0 провалено.
- Реальный HTTP smoke-test на отдельном сервере и временной SQLite-базе: главная, CRM, категория, товар, favicon, модуль мобильной навигации, robots и sitemap отдавались с ожидаемыми статусами.
- Прямой обход: 19 уникальных маршрутов категорий, 76 опубликованных товарных URL и 6 новостных URL — все вернули HTTP 200.
- Sitemap содержит 101 URL; фактические страницы из карты проверяются на существование отдельно.
- Рабочая CRM-база не использовалась: сервер был запущен с отдельным временным `DATA_DIR`.

## Ограничения и следующие задачи
- OriginKit Hero 58 ещё не установлен как исходный npm-компонент; в текущей версии используется адаптация визуального направления.
- React Bits SpotlightCard требует загрузки React ESM runtime с внешнего CDN. При недоступности сети остаются обычные серверные карточки без интерактивного Spotlight. Для production лучше включить React runtime в локальную сборку после подготовки полноценного frontend build pipeline.
- Полноценный переход публичной витрины на React/Vite не выполнялся; CRM и backend не переписывались.
- Chroma Grid отложен до появления проверенных товарных фотографий.
- Реальная визуальная проверка браузерного рендеринга через Chromium в этой среде не выполнилась: Chromium блокировал локальный HTTP URL политикой среды. Поэтому CSS/JS были проверены статически, а HTTP-ответы и HTML — через прямые запросы. Требуется дополнительный визуальный просмотр в браузере на компьютере пользователя.
- Исследование поисковой частотности категорий не входило в этот этап; текущие URL — рабочая информационная архитектура, не подтверждённая семантическими объёмами.
- Блюр изображений, возрастная проверка и ограничения 18+ не реализованы по согласованному решению.
- Публикация и миграция на production не выполнялись.


## Статус после Phase 5

Указанный выше browser ESM import map через `esm.sh` удалён в Phase 5. В промежуточной рабочей копии Phase 5 был добавлен source-компонент SpotlightCard; в Phase 6 upstream-файл исключён из передаваемого ZIP и заменён прямым официальным установщиком/адаптером. На серверных SSR-страницах остаётся независимый VAPELAB fallback до production build.

# VAPELAB Stage 4 — этап 2: публичные страницы каталога

Дата контрольной проверки: 2026-11-23

## Что реализовано

- Добавлена таблица `store_category_pages` для публичных SEO-страниц категорий и связующая таблица `store_category_page_categories`.
- 18 корневых категорий исходного каталога распределены по 14 пользовательским URL. Похожие по смыслу исходные разделы объединены на уровне страницы, но остаются самостоятельными категориями в базе и в содержимом страницы.
- Пять обнаруженных вложенных категорий имеют отдельные URL.
- У опубликованных товаров есть страницы `/product/:slug`.
- У опубликованных новостей есть страницы `/news/:slug`.
- Информационные страницы открываются только при `status='published'` и `legal_review_status='approved'`.
- На серверных страницах выводятся H1, title, description, canonical, robots, Open Graph и хлебные крошки.
- Ссылки с главной и из карточек ведут на отдельные URL категорий и товаров.
- Старые URL корневых категорий, для которых назначен короткий маршрут, перенаправляются кодом 301.
- Пустая категория остаётся доступной для навигации, но получает `noindex, nofollow` и не попадает в sitemap.
- Sitemap формируется по данным БД и включает только опубликованные индексируемые страницы. URL с внешним canonical, query string или hash исключаются.
- Внешние ссылки на источники в публичных карточках принимают только HTTP(S)-адреса.

## Контрольная полнота тестовой базы

- 18 корневых записей категорий.
- 5 вложенных записей категорий.
- 19 уникальных публичных маршрутов категорий (14 верхнеуровневых страниц и 5 вложенных страниц).
- 76 опубликованных демонстрационных карточек товаров.
- 6 опубликованных новостей.
- 1 вложенная категория `/armyanskie-sigarety` пока не имеет опубликованных связанных товаров: маршрут отвечает 200 для навигации, но страница помечена `noindex` и исключена из sitemap.
- В таблице `store_pages` на тестовой базе не было информационных страниц, прошедших `legal_review_status='approved'`; такие записи не добавлялись в sitemap.

## Sitemap на момент проверки

Всего 101 URL:

- главная — 1;
- индексируемые категории — 18;
- товары — 76;
- новости — 6;
- информационные страницы — 0.

Sitemap XML проверен парсером. Все 101 URL из sitemap проверены прямыми HTTP-запросами: каждый вернул 200. Для всех не-корневых HTML-страниц проверено отсутствие `X-Robots-Tag: noindex` и совпадение canonical с URL из sitemap.

## Что не следует считать завершённым

- Человекопонятные slugs являются рабочей информационной архитектурой, но ещё не подтверждены исследованием частотности запросов и поискового спроса.
- Реальные оригинальные фотографии товаров не были получены; страницы показывают нейтральный графический placeholder, если фото отсутствует.
- Тексты SEO-описаний категорий пока базовые и требуют редакторской доработки после анализа семантики.
- Главная страница пока не переработана под короткую структуру «информация о компании → ключевые категории»; она остаётся задачей следующего визуального этапа.
- Чёрно-белая дизайн-система, настоящий OriginKit Hero 58 и настоящие React Bits компоненты ещё не интегрированы в этой контрольной точке.
- Блюр изображений, возрастной gate и другие ограничения 18+ намеренно не реализованы и остаются отложенными.
- Публикация на сервер не выполнялась.

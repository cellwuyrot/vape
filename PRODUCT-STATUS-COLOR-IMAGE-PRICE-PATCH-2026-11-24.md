# VAPELAB — статусы каталога, цвета, фотографии и цены вариантов

## Что изменено

### Единый статус товара

В административной панели доступны ровно четыре статуса:

- `hidden` — «Скрыт»: не показывается в каталоге, поиске, рекомендациях и sitemap; URL карточки недоступен; `noindex`.
- `active` — «Показан и продаётся»: публичная карточка доступна, бронирование разрешено с учётом флага товара.
- `out_of_stock` — «Показан, но нет в наличии»: карточка остаётся публичной и индексируемой, но бронирование отклоняется с HTTP 409.
- `draft` — «Черновик»: не публикуется, не индексируется и отсутствует в sitemap.

Публикация и наличие больше не управляются разными селекторами. Старые внутренние значения базы данных совместимо преобразуются в эти четыре состояния. Остальные существующие сущности (новости и контентные страницы) сохраняют собственные статусы — изменение касается только карточек товаров.

### Автопривязка фотографий по цвету

Добавлена строгая привязка по точному названию варианта:

1. `images/<slug товара>/<точное название цвета>.jpg`
   Пример: `images/mok-fwrd/Синий.jpg`
2. `<slug товара>__<точное название цвета>.jpg`
   Пример: `mok-fwrd__Синий.jpg`
3. Также распознаётся имя файла с префиксом полного названия товара: `MOK FWRD Синий.jpg`.

В админке:

- в редакторе карточки есть кнопка «Сохранить цвета и сопоставить фотографии»;
- в разделе фотографий есть кнопка «Автоматически связать фото с цветами»;
- фотографию можно выбрать вручную у соответствующего цветового варианта.

Сопоставление точное. `Синий.jpg` не назначится варианту «Тёмно-синий». Папка должна соответствовать slug/названию/SKU карточки. Неоднозначные и неподходящие изображения остаются без связи для ручного выбора.

### Цены вариантов

В списке товаров нажатие на название карточки раскрывает её варианты, цены, старые цены, SKU и наличие связанной фотографии. Основная цена товара остаётся резервной, когда у вариантов индивидуальные цены.

### XLSX-шаблон

`templates/VAPELAB-products-template.xlsx` обновлён:

- 44 поля;
- один столбец статуса товара с кодами `hidden`, `active`, `out_of_stock`, `draft`;
- отдельное поле индексации убрано: индексирование определяется статусом;
- инструкция дополнена формулой имён фотографий и правилами вариантов.

## Установка

Поместите этот архив в `/var/www/vapelab`, затем выполните:

```bash
cd /var/www/vapelab/app || exit 1

BACKUP="/root/vapelab-before-product-status-$(date +%F-%H%M%S).tar.gz"
tar -czf "$BACKUP" --exclude=node_modules --exclude=data --exclude=logs --exclude='.env*' .
chmod 600 "$BACKUP"

unzip -o /var/www/vapelab/VAPELAB-product-status-color-images-prices-2026-11-24.zip -d .

export PATH=/root/.nvm/versions/node/v22.22.2/bin:$PATH
npm run check
```

Только если проверка прошла:

```bash
pm2 restart vapelab --update-env
pm2 save
```

Миграция 018 применяется автоматически при запуске, если ещё не применена. Если она уже есть в таблице миграций, повторно не выполняется.

Архив не содержит `.env`, `data/`, `logs/` или `node_modules/`. Не удаляйте и не заменяйте эти каталоги при обновлении.

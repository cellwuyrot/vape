VAPELAB — COLOR VARIANTS UPDATE
Build date: 2026-11-24

Что меняется:
- в CRM карточке товара добавлен блок «Цветовые варианты»;
- к каждому цвету можно привязать свою фотографию из уже загруженных фото товара;
- на публичной карточке цвета показаны текстовыми кнопками;
- выбор цвета переключает главное фото и галерею на изображения этого цвета;
- цена/наличие/артикул варианта передаются в запрос бронирования, если заданы;
- повторный блок вариантов внизу карточки не выводится;
- при бронировании сохраняются выбранный вариант и снимок URL его изображения;
- добавлена миграция 016 для хранения выбранного варианта в заявке.

Установка:
1. Сделайте резервную копию проекта (без необходимости архивировать node_modules).
2. Распакуйте содержимое ZIP поверх /var/www/vapelab/app.
3. Не заменяйте .env, папки data/ и logs/.
4. Запустите npm run check в проекте.
5. Только после успешного завершения проверьте pm2 restart vapelab --update-env && pm2 save.
   При старте приложение применяет миграцию 016 автоматически.

Файлы миграции уже включены. Если миграция 016 уже применена на сервере, runner пропустит её по журналу миграций.

Админка:
- Сначала загрузите фотографии в карточку товара в обычном блоке «Фотографии».
- Затем откройте «Редактировать товар».
- В «Цветовых вариантах» добавьте цвет и выберите соответствующее фото.
- Сохраните карточку.

Для одного цвета сейчас выбирается одно основное изображение. Общие фотографии карточки остаются доступными как fallback, если у варианта не назначено фото.

# Аудит публичного каталога vapelab.site для подготовки импорта

Дата просмотра: 23 ноября 2026 года. Источник: публичные HTML-страницы `https://vapelab.site/`, страницы коллекций `/collection/...` и карточек `/product/...`.

Список отражает доступные названия разделов на момент просмотра; это не подтверждение наличия каждой позиции на складе.

## Данные, которые можно собирать с открытых страниц

| Поле | Источник | Ограничение |
|---|---|---|
| Название | H1, JSON-LD Product, og:title | H1 предпочтительнее общих названий в меню |
| Категория / подкатегория | Ссылка на коллекцию, меню, хлебные крошки | У одного товара может быть несколько категорий; основную нужно проверить вручную |
| Описание | JSON-LD Product, видимый блок описания, meta description | Скрипт сохраняет несколько наблюдений и выбирает наиболее содержательное описание; человек проверяет итог |
| Характеристики | JSON-LD `additionalProperty`, таблицы, списки и строки `Название: значение` | Разметка зависит от шаблона карточки; не все свойства структурированы |
| Цена / старая цена | Offer JSON-LD, карточка в коллекции | Цена может отсутствовать или отличаться между страницей товара и списком; конфликт отмечается для проверки |
| Наличие | Offer JSON-LD и подпись карточки | Статус может отличаться между коллекцией и детальной страницей |
| SKU / артикул | JSON-LD `sku` / `mpn`, если они опубликованы | На части страниц код товара не виден; нельзя конструировать его из названия |
| Бренд | JSON-LD `brand` | Если поле не опубликовано отдельно, его нельзя считать подтверждённым только по похожему слову в описании |
| Варианты | JSON-LD `hasVariant`, `color`, `name`, Offer | Варианты без машинной разметки не следует автоматически превращать в отдельные SKU |
| Фото | `image`, og:image, изображения внутри блока товара | URL фото сохраняется вместе со страницей-источником; скачивание включается отдельно и требует прав на копирование |
| SEO | `<title>`, meta description, H1, canonical | Ключевые слова готовит Qwen как черновик по фактам; поисковую частотность он не выдумывает |

### Пример расхождения, которое нельзя исправлять догадкой

У коллекции Glo Air на момент просмотра отображаются три позиции — Белый, Графит и Хаки — с ценой 1 300 ₽. На странице Glo Air Белый отображается статус «Предзаказ». На странице есть фактическое описание и список характеристик: корпус из анодированного алюминия с Soft touch, индукционный нагрев, зарядка 90 минут, Standard/Boost, нагрев 20 секунд, масса 76 г, индикация заряда и перечисленная совместимость со стиками.

Это подтверждает полезность одновременного сохранения данных коллекции и detail page. Если цена, наличие или название отличаются, скрипт сохраняет обе версии с URL-источником и ставит флаг ручной проверки. Автоматически «выбирать правильную» цену он не должен.

## Что намеренно не генерируется

- SKU и артикулы, если их нет в источнике.
- Цена, старая цена и наличие, если их нет в открытой разметке.
- Частотность поисковых запросов, сертификаты, гарантии, медицинские свойства и прочие неподтверждённые утверждения.
- Возрастная классификация как окончательный вердикт. Скрипт выставляет флаг проверки для категорий, похожих на табак/никотин, а решение принимает администратор.
- Статус публикации, индексация и возможность бронирования. Каждый товар импортируется как `draft`, `noindex`, `is_reservable=0`.

Парсер не обходит авторизацию, CAPTCHA, paywall, антибот-защиту и запреты robots.txt. Изображения сохраняются только по отдельному флагу `--download-images`; перед копированием владелец должен проверить право использовать эти файлы. Скрипт не меняет исходный сайт и не оформляет покупки.

В нижней части публичной страницы сайта размещено уведомление о информационном характере материалов и отсутствии дистанционной реализации никотиносодержащей продукции и устройств. Поэтому импортируемые данные — только черновой справочник для последующей юридической и редакторской проверки, а не готовые к публикации предложения.


## Проверенные публичные источники

Наблюдения в этом документе сделаны по открытым страницам сайта на 23 ноября 2026 года; каталог может изменяться:

- Главная и каталог категорий: https://vapelab.site/

- Карточка Glo Air Белый: https://vapelab.site/product/glo-air-belyy

Перед повторным сбором парсер проверяет `robots.txt`. Ответы HTTP 401, 403 и 429 трактуются как отказ/ограничение доступа и не могут быть обойдены флагом `--owner-confirmed`. Внешние CDN проверяются по собственному `robots.txt`.

VAPELAB — исправление фотографий и вариантов товара

Архив содержит только изменённые исходные файлы. Он не содержит и не заменяет:
- .env;
- базу данных и каталог data/;
- загруженные изображения public/uploads/;
- конфигурацию Nginx, PM2 или SMTP.

Установка на сервере:
1. Перейти в каталог проекта.
2. Сделать резервную копию перечисленных в архиве файлов.
3. Распаковать архив поверх проекта с сохранением структуры папок.
4. Выполнить npm run check.
5. Только при успешной проверке выполнить pm2 restart vapelab --update-env.

Пример:
cd /var/www/vapelab/app
unzip -o /root/VAPELAB-product-variant-image-fix-2026-11-24.zip -d .
npm run check
pm2 restart vapelab --update-env

Перед распаковкой сделайте резервную копию файлов. Новая миграция базы не нужна.

После обновления:
Админка → Товары → открыть товар → «Варианты и фото».
Создайте/проверьте варианты, загрузите изображения внутри нужного варианта
или назначьте уже загруженные изображения через поле «Привязать к».
Для автоматического сопоставления папки изображений используйте:
images/<product-slug>/<точное название варианта>/01-main.jpg

Старые изображения без variant_id останутся общими фото товара, автоматически
назначать их по догадке система не будет.

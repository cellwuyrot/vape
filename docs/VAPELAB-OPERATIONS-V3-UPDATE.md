# VAPELAB Operations v3 — изменения

## Витрина и управление товарами

- В CRM добавлен массовый выбор товаров с сохранением выделения между страницами.
- Массовые действия: публикация, скрытие, архивирование, изменение складского статуса и удаление.
- За одну операцию можно обработать до 100 товаров; сервер отклоняет превышение лимита.
- При удалении товара снимается назначение товара-представителя с категорий.
- Статус наличия поддерживается в карточке товара, массовых операциях, XLSX/CSV-импорте и Python/Qwen-парсере.

## Оповещения о поступлении

- Публичная форма принимает e-mail и/или Telegram, требует отдельного согласия и возрастного подтверждения для позиций 18+.
- Если Telegram уже привязан к аккаунту покупателя, используется существующий Telegram chat ID.
- Иначе покупателю формируется одноразовая ссылка на бота. После `/start` подписка связывается с Telegram-чатом.
- Если товар уже вернулся в наличие к моменту привязки Telegram, бот отправляет уведомление сразу.
- В CRM есть список подписок, статусы фактической доставки и повторная отправка для товара в наличии.

## Покупательский кабинет и CRM

- Профиль покупателя хранит имя, телефон, Telegram username, адрес, город, индекс и комментарий к доставке.
- Кабинет показывает историю заказов, бронирований и диалогов с CRM.
- Привязанный Telegram работает как канал переписки: входящие сообщения попадают в CRM-инбокс, ответы менеджера возвращаются в Telegram. Вход в веб-кабинет по-прежнему выполняется по e-mail-коду; Telegram здесь подключает канал общения, а не заменяет e-mail-аутентификацию.
- Обзор показывает воронку по каждому ответственному и общую строку по выбранной воронке.
- Из раздела «Сделки» удалена подсказка о перетаскивании карточки.

## Страницы и рекомендации

- Ссылка на оптовое направление ведёт на `/optovy` из шапки и подвала.
- Страница `optovy` создаётся миграцией 014 черновиком. Администратор заполняет её в `Витрина → Страницы` и публикует после проверки.
- Подборка «Возможно, вас заинтересует» формируется детерминированно по хешу даты и ID товара: один набор из максимум восьми позиций для всех посетителей в течение суток, затем набор меняется. Общая подборка не показывает товары 18+ без возрастного контекста.

## Конфигурация Telegram

В `.env` должны быть заданы:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_BOT_USERNAME=
TELEGRAM_WEBHOOK_SECRET=
PUBLIC_URL=https://ваш-домен
```

`TELEGRAM_BOT_USERNAME` указывается без `@`. Вебхук требует доступного из интернета HTTPS-адреса. На `localhost` Telegram не сможет доставлять обновления без публичного туннеля.

## Данные и миграции

Новая миграция не требуется: складской статус, подписки о поступлении, поля профиля покупателя и страница `/optovy` уже находятся в миграции 014. Обновление можно накатывать поверх базы, в которой миграция 014 уже применена.

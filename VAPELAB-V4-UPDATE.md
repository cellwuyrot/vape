# VAPELAB — обновление V4

## Что изменено

- Исправлена публикация и выдача `/optovy`: миграция 015 публикует существующую страницу и снимает требование проверки юридического документа для этой информационной страницы. Маршрут работает и без `PUBLIC_URL`.
- Убраны «Опт» и «О компании» из верхней навигации витрины. Ссылка «О компании» в подвале и сама информационная секция сохранены.
- Убран отдельный пункт «Сделки» из меню CRM и поиска. Исторические записи и серверная модель сделок не удаляются.
- Настройки CRM собраны в компактные раскрывающиеся группы.
- В разделе «Заказы» добавлена отдельная вкладка «Поставки» с импортом XLSX/CSV, сопоставлением колонок, реквизитами поставщика и накладной, предпросмотром и детализацией поставки.
- При подтверждении приёмки остаток увеличивается только у товаров, найденных в CRM по SKU или точному названию. Розничная цена не изменяется. Несопоставленные строки сохраняются в поставке.
- Добавлены таблицы `supplies` и `supply_items`, а также включение их данных в резервное копирование.

## Установка обновления

1. Сделайте резервную копию текущего проекта и базы данных.
2. Распакуйте архив поверх текущего проекта с заменой файлов.
3. Не удаляйте и не заменяйте свой `.env`, каталог `data` и пользовательские файлы в `public/uploads`.
4. В корне проекта выполните `npm run build:storefront`, чтобы пересобрать React-витрину после обновления исходников.
5. Запустите приложение обычным для вашей среды способом. При старте сервер автоматически применит миграцию 015.

Если зависимости Vite ещё не установлены, вместо шага 4 сначала выполните `npm run setup:storefront`.

## Примечание по поставкам

В первой строке Excel/CSV должны быть заголовки колонок. Обязательны наименование и количество; остальные колонки сопоставляются автоматически или вручную. Поддерживаются `.xlsx` и `.csv`; старый бинарный `.xls` нужно предварительно сохранить как `.xlsx`. Исходная таблица разбирается в строки поставки; для фактического изменения остатков товар должен быть сопоставлен с каталогом по SKU или точному названию.

## Почтовый сервер VAPELAB

- Добавлен единый ящик `info@vapelab.bond` с SMTP-отправкой и IMAP-чтением писем.
- В CRM добавлен администраторский раздел «Почта»: папки, список писем, чтение, ответ и создание письма.
- Добавлены проверки A/MX/PTR/SPF/DKIM/DMARC, SMTP TLS и IMAP-аутентификации.
- Добавлена отдельная Docker Mailserver-конфигурация, preflight/post-deploy скрипты и инструкция в `mail-server/README.md`.
- Живой приём/отправка не могут считаться проверенными до публикации DNS/PTR, открытия портов и теста с внешними почтовыми провайдерами.

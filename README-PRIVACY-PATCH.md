# VAPELAB — сокрытие основного администратора

## Что делает патч

- Не возвращает e-mail основного администратора (`superadmin`) в `/api/auth/me` и `/api/auth/verify-code`.
- Не включает запись `superadmin` в список сотрудников `/api/users`.
- Если профиль основного администратора запрашивается напрямую, отдаёт безопасное представление: `Рабочий аккаунт`, без e-mail.
- В боковой панели и настройках CRM показывает нейтральную подпись; почта отображается как `Скрыта`.
- Маскирует имя основного администратора в лентах активности, задачах и сводке сделок.
- Не меняет внутреннюю роль, реальный адрес в БД, `ADMIN_EMAIL`, доставку OTP или права доступа.

## Установка

1. Сделайте резервную копию проекта и базы данных.
2. Распакуйте архив в корень `/var/www/vapelab/app` с заменой одноимённых файлов.
3. Используйте Node.js 22:

   ```bash
   export PATH=/root/.nvm/versions/node/v22.22.2/bin:$PATH
   cd /var/www/vapelab/app
   npm run check
   ```

4. Только если проверка завершилась успешно:

   ```bash
   pm2 restart vapelab --update-env
   pm2 save
   ```

5. Перезагрузите CRM в браузере. При необходимости выйдите и войдите снова, чтобы обновить данные профиля.

Патч не содержит `.env`, `data/`, `logs/`, файлов изображений или базы данных. Он не меняет пароль/OTP и не удаляет учётную запись.
